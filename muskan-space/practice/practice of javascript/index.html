JavaScript Basics

1.what is javascript?

Ans. JavaScript is a versatile, high-level programming language primarily used for creating interactive and dynamic content on websites. It is a core technology of the web, alongside HTML and CSS, and enables developers to implement complex features such as real-time updates, animations, and form validations.

2.What are the different data types in JavaScript?

Ans. JavaScript has the following data types:

  • Primitive Types:
    • String: Represents textual data, e.g., "Hello".
    • Number: Represents numeric values, e.g., 42 or 3.14.
    • Boolean: Represents true or false values.
    • Undefined: A variable that has been declared but not assigned a value.
    • Null: Represents an intentional absence of value.
    • Symbol: Represents a unique and immutable value (introduced in ES6).
    • BigInt: Represents integers with arbitrary precision (introduced in ES11).
  • Non-Primitive Types:
    • Object: Represents collections of key-value pairs or more complex entities, e.g., arrays, functions, and objects.

3.What is the difference between var, let, and const?

Ans. The difference between var, let, and const lies in their scope, hoisting, and mutability:

  • var:
    • Function-scoped: Accessible within the function where it is declared.
    • Hoisted: Can be used before declaration, but its value will be undefined.
    • Can be re-declared and updated.
  • let:
    • Block-scoped: Accessible only within the block where it is declared.
    • Not hoisted in the same way as var: Cannot be used before declaration.
    • Can be updated but not re-declared in the same scope.
  • const:
    • Block-scoped: Similar to let, accessible only within the block where it is declared.
    • Not hoisted in the same way as var: Cannot be used before declaration.
    • Cannot be updated or re-declared. The value is immutable, but for objects, the properties can still be modified.

4.How does JavaScript handle type coercion?

Ans. JavaScript handles type coercion by automatically converting values from one type to another when performing operations. This can happen in two ways:

  • Implicit Coercion: JavaScript automatically converts types when it expects a specific type. For example:
    • '5' + 2 results in '52' (string concatenation).
    • '5' - 2 results in 3 (string converted to number).
  • Explicit Coercion: Developers manually convert types using functions like Number(), String(), or Boolean(). For example:
    • Number('42') converts the string '42' to the number 42.
    • Boolean(0) converts 0 to false.

5.What is the difference between == and ===?

Ans. The key difference between == and === lies in type coercion:

  • ==: Performs type conversion if the types of the operands are different before comparing their values. For example:
    • '10' == 10 evaluates to true because the string '10' is converted to a number.
  • ===: Does not perform type conversion and checks both value and type. For example:
    • '10' === 10 evaluates to false because one is a string and the other is a number.

1.What are the different ways to create an object in JavaScript?

Ans. There are several ways to create an object in JavaScript:

  • Object Literals: The simplest way to create an object. 
    const obj = { key: 'value' };

                    function Person(name, age) {

                        this.age = age;
                    }

                    function createPerson(name, age) {

2.What is the difference between deep copy and shallow copy?

Ans. The difference between deep copy and shallow copy lies in how they duplicate objects:

  • Shallow Copy:
    • Copies only the first level of the object. Nested objects or arrays are not duplicated but referenced.
    • Changes to nested objects in the copied object will affect the original object.
    • Examples: Object.assign(), spread operator ({...obj}).
  • Deep Copy:
    • Creates a complete copy of the object, including all nested objects or arrays.
    • Changes to the copied object do not affect the original object.
    • Examples: Using libraries like lodash (_.cloneDeep()) or structured cloning (structuredClone() in modern browsers).

3.How can you iterate over an array in JavaScript?

Ans. There are several ways to iterate over an array in JavaScript:

  • for Loop: A traditional way to iterate over an array. 
    
for (let i = 0; i < array.length; i++) {
    console.log(array[i]);
}
  • for...of Loop: A modern way to iterate over iterable objects like arrays. 
    
for (const element of array) {
    console.log(element);
}
  • forEach Method: Executes a provided function once for each array element. 
    
array.forEach(element => {
    console.log(element);
});
  • map Method: Creates a new array by applying a function to each element. 
    
const newArray = array.map(element => element * 2);
console.log(newArray);
  • while Loop: Iterates as long as a specified condition is true. 
    
let i = 0;
while (i < array.length) {
    console.log(array[i]);
    i++;
}
  • do...while Loop: Executes the loop body at least once before checking the condition. 
    
let i = 0;
do {
    console.log(array[i]);
    i++;
} while (i < array.length);

ES6+ Features

1.What are template literals?

Ans. Template literals, introduced in ES6, are a way to create strings in JavaScript that allow embedded expressions and multi-line strings. They are enclosed by backticks (`) instead of single or double quotes. Template literals support:

  • String Interpolation: Embed expressions using the ${expression} syntax. 
    
                    const name = 'Alice';
                    const greeting = `Hello, ${name}!`;
                    console.log(greeting); // Output: Hello, Alice!
  • Multi-line Strings: Create strings that span multiple lines without using escape characters. 
    
                    const multiLine = `This is a
                    multi-line string.`;
                    console.log(multiLine);
                    // Output:
                    // This is a
                    // multi-line string.
  • Expression Evaluation: Include any valid JavaScript expression inside the template. 
    
                    const a = 10;
                    const b = 20;
                    console.log(`The sum of a and b is ${a + b}.`); // Output: The sum of a and b is 30.

2.What is destructuring in JavaScript?

Ans. Destructuring in JavaScript is a syntax introduced in ES6 that allows you to unpack values from arrays or properties from objects into distinct variables. It simplifies the process of extracting data from complex structures.

Examples:

  • Array Destructuring: 
    
const [a, b] = [1, 2];
console.log(a); // Output: 1
console.log(b); // Output: 2
  • Object Destructuring: 
    
const { name, age } = { name: 'Alice', age: 25 };
console.log(name); // Output: Alice
console.log(age); // Output: 25
  • Default Values: 
    
const [x, y = 10] = [5];
console.log(x); // Output: 5
console.log(y); // Output: 10
  • Nested Destructuring: 
    
const { info: { city } } = { info: { city: 'New York' } };
console.log(city); // Output: New York

4.What are arrow functions, and how do they differ from regular functions?

Ans. Arrow functions, introduced in ES6, are a concise syntax for writing functions in JavaScript. They differ from regular functions in several ways:

  • Simplified Syntax: Arrow functions have a shorter syntax compared to regular functions. 
    
// Regular function
function add(a, b) {
    return a + b;
}

// Arrow function
const add = (a, b) => a + b;
  • No Binding of this: Arrow functions do not have their own this. Instead, they inherit this from the surrounding lexical scope. 
    
class Example {
    constructor() {
        this.value = 42;
    }

    regularFunction() {
        setTimeout(function() {
            console.log(this.value); // undefined (this refers to the global object)
        }, 1000);
    }

    arrowFunction() {
        setTimeout(() => {
            console.log(this.value); // 42 (this refers to the instance of Example)
        }, 1000);
    }
}

const example = new Example();
example.regularFunction();
example.arrowFunction();
  • Cannot Be Used as Constructors: Arrow functions cannot be used with the new keyword and do not have a prototype property.
  • No Arguments Object: Arrow functions do not have their own arguments object. Use rest parameters instead. 
    
const arrowFunc = (...args) => console.log(args);
arrowFunc(1, 2, 3); // Output: [1, 2, 3]

5What are rest and spread operators?

Ans. The rest and spread operators are features introduced in ES6 that simplify working with arrays, objects, and function arguments:

  • Rest Operator:
    • Used to collect all remaining elements into an array or object.
    • Syntax: ... (three dots).
    • Commonly used in function parameters to handle variable numbers of arguments.
    • Example: 
      
function sum(...numbers) {
    return numbers.reduce((total, num) => total + num, 0);
}
console.log(sum(1, 2, 3, 4)); // Output: 10
  • Spread Operator:
    • Used to expand an array or object into individual elements.
    • Syntax: ... (three dots).
    • Commonly used for copying or merging arrays and objects.
    • Example: 
      
// Expanding an array
const numbers = [1, 2, 3];
console.log(...numbers); // Output: 1 2 3

// Merging arrays
const moreNumbers = [4, 5, 6];
const combined = [...numbers, ...moreNumbers];
console.log(combined); // Output: [1, 2, 3, 4, 5, 6]

// Copying an object
const obj = { a: 1, b: 2 };
const copiedObj = { ...obj, c: 3 };
console.log(copiedObj); // Output: { a: 1, b: 2, c: 3 }

6What are modules in JavaScript, and how do you export/import them?

Ans. Modules in JavaScript are reusable pieces of code that can be exported from one file and imported into another. They help in organizing code, improving maintainability, and avoiding global namespace pollution. JavaScript modules are supported natively in modern browsers and Node.js.

  • Exporting: You can export variables, functions, or classes from a module using the export keyword. 
    
// Named export
export const greet = () => console.log('Hello!');

// Default export
export default function sayGoodbye() {
    console.log('Goodbye!');
}
  • Importing: You can import the exported members into another file using the import keyword. 
    
// Importing named exports
import { greet } from './module.js';

// Importing default export
import sayGoodbye from './module.js';

// Importing both named and default exports
import sayGoodbye, { greet } from './module.js';

3.What is event bubbling and event delegation?

Ans. Event bubbling and event delegation are concepts in JavaScript related to how events propagate through the DOM:

  • Event Bubbling:
    • When an event occurs on an element, it first triggers the event handlers on that element, and then it propagates (or "bubbles") up to its ancestors in the DOM tree.
    • For example, if you click on a button inside a div, the click event will first trigger the button's event handler and then the div's event handler.
  • Event Delegation:
    • A technique that leverages event bubbling to handle events at a higher level in the DOM, rather than attaching event listeners to individual elements.
    • Useful for dynamically added elements, as the parent element can handle events for its children.
    • Example: 
      
document.querySelector('ul').addEventListener('click', function(event) {
    if (event.target.tagName === 'LI') {
        console.log('List item clicked:', event.target.textContent);
    }
});

4.How do you prevent default behavior of an event?

Ans. To prevent the default behavior of an event in JavaScript, you can use the preventDefault() method. This method stops the browser's default action associated with the event. For example:


document.querySelector('a').addEventListener('click', function(event) {
    event.preventDefault(); // Prevents the default action of navigating to the link's href
    console.log('Default behavior prevented!');

Performance & Optimization

1.What is debouncing and throttling in JavaScript?

Ans. Debouncing and throttling are techniques used to control the rate at which a function is executed, especially in response to events like scrolling, resizing, or typing:

  • Debouncing:
    • Ensures that a function is executed only after a specified delay has passed since the last time it was invoked.
    • Useful for scenarios like search input, where the function should only execute after the user has stopped typing.
    • Example: 
      
function debounce(func, delay) {
    let timer;
    return function(...args) {
        clearTimeout(timer);
        timer = setTimeout(() => func.apply(this, args), delay);
    };
}

const debouncedFunction = debounce(() => console.log('Debounced!'), 300);
window.addEventListener('resize', debouncedFunction);
  • Throttling:
    • Ensures that a function is executed at most once in a specified interval, regardless of how many times the event is triggered.
    • Useful for scenarios like scroll events, where the function should execute at regular intervals.
    • Example: 
      
function throttle(func, interval) {
    let lastCall = 0;
    return function(...args) {
        const now = Date.now();
        if (now - lastCall >= interval) {
            lastCall = now;
            func.apply(this, args);
        }
    };
}

const throttledFunction = throttle(() => console.log('Throttled!'), 300);
window.addEventListener('scroll', throttledFunction);

2.How can you improve the performance of JavaScript code?

Ans. Improving the performance of JavaScript code involves several strategies:

  • Minimize DOM Manipulations: Reduce the number of DOM manipulations by batching updates or using Document Fragments.
  • Debounce and Throttle Events: Use debouncing or throttling for events like scroll, resize, or keypress to limit the frequency of function execution.
  • Use Efficient Loops: Prefer for loops over forEach or other higher-order functions for performance-critical code.
  • Lazy Loading: Load resources like images, scripts, or components only when they are needed.
  • Code Splitting: Split your JavaScript code into smaller chunks to load only the necessary parts initially.
  • Optimize JavaScript Execution: Avoid blocking the main thread by using Web Workers for heavy computations.
  • Reduce Unnecessary Repaints and Reflows: Minimize layout thrashing by batching style changes and avoiding inline styles.
  • Use Modern JavaScript Features: Leverage ES6+ features like let, const, and arrow functions for cleaner and more efficient code.
  • Cache Results: Cache the results of expensive operations or API calls to avoid redundant computations.
  • Use a Content Delivery Network (CDN): Serve static assets like JavaScript files from a CDN to reduce latency.
  • Minify and Bundle JavaScript: Use tools like Webpack or Rollup to minify and bundle your JavaScript files for faster loading.
  • Remove Unused Code: Use tools like Tree Shaking to eliminate dead code from your JavaScript bundles.

3.What is lazy loading in JavaScript?

Ans. Lazy loading in JavaScript is a design pattern that delays the loading of resources or objects until they are actually needed. This helps improve the performance of web applications by reducing the initial load time and conserving bandwidth. For example, images or scripts can be loaded only when they come into the viewport or are required for a specific interaction. Lazy loading can be implemented using techniques like the Intersection Observer API or by dynamically importing modules using import() in modern JavaScript.

Error Handling & Debugging

1.What is the difference between try...catch and throw?

Ans. The difference between try...catch and throw lies in their purpose and usage:

  • try...catch:
    • Used to handle exceptions in a block of code.
    • The try block contains the code that may throw an error.
    • The catch block is executed if an error is thrown in the try block, allowing you to handle the error gracefully.
    • Example: 
      
try {
    let result = riskyOperation();
    console.log(result);
} catch (error) {
    console.error('An error occurred:', error.message);
}
  • throw:
    • Used to manually throw an error or exception.
    • When an error is thrown, the normal execution of the code stops, and control is passed to the nearest catch block.
    • Example: 
      
function riskyOperation() {
    if (Math.random() > 0.5) {
        throw new Error('Something went wrong!');
    }
    return 'Success!';
}

3.What are common JavaScript errors and how do you fix them?

Ans. Common JavaScript errors and their fixes include:

  • ReferenceError: Occurs when trying to access a variable that is not defined.
    • Fix: Ensure the variable is declared before use.
  • TypeError: Happens when an operation is performed on a value of the wrong type.
    • Fix: Check the type of the variable before performing operations.
  • SyntaxError: Caused by incorrect syntax in the code.
    • Fix: Review the code for syntax issues, such as missing brackets or semicolons.
  • RangeError: Occurs when a number is outside the allowable range.
    • Fix: Ensure numbers are within the valid range for the operation.
  • URIError: Happens when there is an issue with encoding or decoding a URI.
    • Fix: Verify the URI and ensure proper encoding/decoding methods are used.
  • Logic Errors: These are mistakes in the program logic that cause unexpected behavior.
    • Fix: Debug the code using tools like console.log() or browser developer tools to identify and correct the logic.

JavaScript in the Browser

1.What are cookies, localStorage, and sessionStorage?

Ans. Cookies, localStorage, and sessionStorage are mechanisms for storing data in the browser:

  • Cookies:
    • Small pieces of data stored on the client-side, sent with every HTTP request to the server.
    • Used for session management, user preferences, and tracking.
    • Can have an expiration date and are limited in size (typically 4KB).
  • localStorage:
    • Stores data with no expiration time, meaning the data persists even after the browser is closed and reopened.
    • Accessible only within the same origin (domain and protocol).
    • Typically used for storing larger amounts of data (up to 5MB).
  • sessionStorage:
    • Stores data for the duration of the page session (until the browser tab is closed).
    • Accessible only within the same origin and browser tab.
    • Useful for temporary data storage during a single session.

2.How does JavaScript handle CORS?

Ans. Cross-Origin Resource Sharing (CORS) is a mechanism that allows restricted resources on a web page to be requested from another domain outside the domain from which the first resource was served. JavaScript handles CORS through the browser's implementation of the Same-Origin Policy (SOP). When making requests to a different origin, the server must include specific CORS headers (e.g., Access-Control-Allow-Origin) in its response to indicate that the request is allowed. If these headers are not present or incorrect, the browser blocks the request for security reasons.
