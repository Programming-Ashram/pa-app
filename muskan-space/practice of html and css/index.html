15.Tell me about input types

Ans.HTML input types are used to define different kinds of input fields in a form. Some common input types include:

  • text: A single-line text input field.
  • password: A single-line text input field that hides the entered characters.
  • email: A field for entering an email address.
  • number: A field for entering a numeric value.
  • date: A field for selecting a date.
  • checkbox: A box that can be checked or unchecked.
  • radio: A circular button that can be selected as part of a group.
  • submit: A button to submit the form data.
  • file: A field for uploading files.
  • hidden:A hidden field that is not displayed to the user.
  • button: A clickable button that can trigger an action or script when clicked.

16.Tell me about attribute of inputs

Ans. Attributes of input elements in HTML define the behavior and appearance of the input fields. Some common attributes include:

  • type: Specifies the type of input (e.g., text, password, email).
  • name: Defines the name of the input field, which is used to identify the field when the form is submitted.
  • value: Sets the default value of the input field.
  • placeholder: Provides a hint to the user about what to enter in the input field.
  • required: Indicates that the input field must be filled out before submitting the form.
  • readonly: Specifies that the input field is read-only and cannot be modified by the user.
  • disabled: Disables the input field, preventing user interaction.
  • maxlength: Sets the maximum number of characters that can be entered in the input field.
  • min: Defines the minimum value for numeric input fields.
  • max: Defines the maximum value for numeric input fields.

5.0 HTML - Basics

1.What is HTML5, and how is it different from previous versions of HTML?

Ans. HTML5 is the latest version of the HyperText Markup Language, designed to structure and present content on the web. It introduces new features and improvements over previous versions, such as:

  • Support for multimedia elements like audio and video without requiring external plugins.
  • New semantic elements like header, footer, article, and section for better content organization.
  • Enhanced form controls with new input types like email, date, and range.
  • Support for offline storage using localStorage and sessionStorage.
  • Canvas and SVG support for drawing graphics and animations.
  • Improved support for responsive design with the viewport meta tag.

HTML5 is backward-compatible and simplifies web development by reducing the need for external libraries and plugins.

2.Why is (!DOCTYPE html) required in HTML5?

Ans. The declaration is required in HTML5 to ensure that the browser renders the page in standards mode, rather than quirks mode. Standards mode enables the browser to interpret the HTML and CSS according to the latest web standards, ensuring consistent behavior across different browsers. It also simplifies the doctype declaration compared to previous versions of HTML.

3.What are semantic elements in HTML5? List some examples.

Ans. Semantic elements in HTML5 are elements that have a clear meaning and structure, making the code more readable and accessible. These elements describe their purpose both to the browser and developers, improving SEO and accessibility.

Examples of semantic elements in HTML5 include:

  • <header>: Represents the header section of a document or a section.
  • <footer>: Represents the footer section of a document or a section.
  • <article>: Represents a self-contained piece of content, such as a blog post or news article.
  • <section>: Represents a thematic grouping of content, typically with a heading.
  • <aside>: Represents content that is tangentially related to the main content, such as a sidebar.
  • <nav>: Represents a section of navigation links.
  • <main>: Represents the main content of the document, excluding repeated elements like headers and footers.
  • <figure>: Represents self-contained content, often with a caption, such as an image or diagram.
  • <figcaption>: Provides a caption for the <figure> element.
  • <mark>: Represents text that is highlighted or marked for reference.

4.What are global attributes in HTML5?

Ans. Global attributes in HTML5 are attributes that can be applied to any HTML element, regardless of its type. These attributes provide additional functionality and control over the elements. Some common global attributes include:

  • id: Specifies a unique identifier for the element.
  • class: Assigns one or more class names to the element for styling or scripting purposes.
  • style: Allows inline CSS styling for the element.
  • title: Provides additional information about the element, often displayed as a tooltip.
  • data-*: Custom data attributes used to store extra information about the element.
  • hidden: Hides the element from view without deleting it from the document.
  • tabindex: Specifies the tab order of the element when navigating with the keyboard.
  • contenteditable: Indicates whether the element's content is editable by the user.
  • draggable: Specifies whether the element can be dragged.
  • lang: Specifies the language of the element's content.
  • dir: Specifies the text direction (e.g., left-to-right or right-to-left).

5.What is the difference between (section), (article), and (div)?

Ans. The difference between section, article, and div lies in their semantic meaning and usage:

  • <section>: Represents a thematic grouping of content, typically with a heading. It is used to divide content into sections that are related to a specific theme or purpose.
  • <article>: Represents a self-contained piece of content that can be independently distributed or reused, such as a blog post, news article, or forum post.
  • <div>: A generic container with no semantic meaning. It is used purely for grouping and styling purposes when no other semantic element is appropriate.

In summary, use section and article for semantic purposes, and div for layout and styling when semantics are not required.

17.How does the viewport meta tag help in responsive design?

Ans. The viewport meta tag helps in responsive design by controlling how a webpage is displayed on different devices. It allows developers to set the width and scaling of the viewport, ensuring that the content adapts to various screen sizes. For example, the tag <meta name="viewport" content="width=device-width, initial-scale=1.0"> sets the viewport width to match the device's screen width and the initial zoom level to 1. This ensures that the webpage is user-friendly and displays correctly on mobile devices, tablets, and desktops.
