1.What is Javascript

OR

Ans: JavaScript is a lightweight, interpreted programming language used to create dynamic and interactive content on web pages. It is a multi-paradigm language, supporting event-driven, functional, and object-oriented programming styles.

1.What is advantages of javascript

Ans: Advantages of JavaScript JavaScript is one of the most widely used programming languages due to its speed, versatility, and ease of use. Here are some key advantages:

a. Speed & Performance 🚀

  • JavaScript runs directly in the browser, making it fast and responsive.
  • No need for compilation—interpreted directly by the browser.
  • Modern engines like V8 (Chrome) and SpiderMonkey (Firefox) optimize JavaScript execution.

b. Easy to Learn & Use 🎯

  • Syntax is simple and beginner-friendly.
  • Works well with HTML & CSS.
  • No need for additional software—just a web browser!

a. Client-Side Execution 🌍

  • Reduces server load by running scripts on the user’s device.
  • Improves user experience with faster responses.

1.What is DOM

Ans: DOM (Document Object Model) is a programming interface for HTML and XML documents. It represents the structure of a web page as a tree-like model, where each element is a node, and JavaScript can interact with it to modify content, styles, and structure dynamically.

1.Difference between querySelector and querySelectorAll ?

Ans: Both querySelector() and querySelectorAll() are used to select elements from the DOM, but they work differently.

1️⃣ querySelector() – Selects the First Matching Element

  • Returns only the first matching element.
  • If no match is found, it returns null.

Example Image:

2️⃣ querySelectorAll() – Selects All Matching Elements

  • Returns a NodeList containing all matching elements.
  • The NodeList is not an array, but you can loop through it.

Example Image:

Which One Should You Use?

  • ✅ Use querySelector() if you only need one element.
  • ✅ Use querySelectorAll() if you need multiple elements.

1.How many type of function ?

Ans: JavaScript provides different types of functions based on their declaration, usage, and behavior. Below are the main types of functions:

1️⃣ Named Function (Regular Function) : A function with a specific name that can be reused multiple times.

2️⃣ Anonymous Function : A function without a name, usually assigned to a variable.

3️⃣ Arrow Function (ES6+) : A shorter syntax for writing functions, introduced in ES6.

4️⃣ Immediately Invoked Function Expression (IIFE) : A function that executes immediately after being defined.

5️⃣ Constructor Function : Used to create objects in JavaScript (before ES6 classes).
